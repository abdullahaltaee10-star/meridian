# MERIDIAN – Ergens is het altijd middag

Landingspagina voor Meridian, een fictief eau-de-colognemerk (schoolproject Arteveldehogeschool, Digitale Vormgeving).
Scroll-beleving van 11:59 naar 12:00 in puur HTML/CSS/JS met GSAP + ScrollTrigger en Lenis. Nieuwsbriefformulier via MailerLite.

- `index.html`, `privacy.html`, `css/`, `js/`, `img/`, `video/`
- `social/`: beelden voor de Figma Buzz-campagne (gekoppeld via de kolom `beeld_url` in de CSV's)
